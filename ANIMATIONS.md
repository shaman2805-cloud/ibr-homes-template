# Анимации IBR HOMES v9

Референс: https://homewoodspa.ru/module, проверен 24.09.2026.
В HTML найдены 67 scroll-триггеров, 30 hover, 8 intoview и появления снизу/сверху/справа/слева. Это количество элементов с учётом адаптивных дублей, не число самостоятельных эффектов.

| Эффект | Реализация в IBR |
|---|---|
| Закрепление сцен | Первый экран, рассказ о доме, горизонтальные карточки, техническая сцена, обзор 360° |
| Горизонтальное движение | Этапы и технические преимущества; закреплённые заголовки, прогресс, остановка в конце |
| Появления | Текст, карточки, FAQ, журнал, кнопки и подвал; разные направления, последовательные задержки |
| Приближение фотографии | Две фотографии дома и смена заголовка на первом экране |
| Сборка конструкции | Видео из референса, перемотка при прокрутке на компьютере; воспроизведение рядом с экраном на телефоне |
| Вращение | 75 кадров из референса, направление связано с прокруткой |
| Размещение на участке | Видео из референса; загрузка и воспроизведение рядом с экраном |
| Круги | Последовательная прорисовка контуров и появление текста |
| Наведение | Стрелки кнопок, увеличение фотографий, движение значков |
| Интерфейс | Анимированные FAQ, модальные окна, шаги формы, фотографии каталога |

Полное совпадение всех кадров, таймингов, состояний и адаптивных вариантов референса не подтверждено. Содержание, фотографии IBR и структура жилых домов адаптированы. Полный текст источника не скопирован.
При уменьшении движения отключаются закрепление и переходы. Форма не требует просмотра всех анимаций.
