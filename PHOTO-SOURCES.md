# Временные фотографии

Фотографии используются в разделе «Архитектурное настроение» как иллюстрации, не как работы IBR HOMES. Люди, сотрудники и отзывы из фотобанков не добавлялись.

1. Современный деревянный дом — Adrien Olichon / Pexels
   https://www.pexels.com/photo/modern-wooden-house-exterior-with-glass-windows-36763997/
2. Интерьер с деревянной мебелью — Rachel Claire / Pexels
   https://www.pexels.com/photo/interior-of-living-room-with-wooden-furniture-4846114/

Лицензия источника: https://www.pexels.com/license/

Фотографии загружаются браузером напрямую с images.pexels.com. Для них нужен интернет. Если источник недоступен, автоматически показываются локальные концепции из прежнего демо. Загрузка обеих внешних фотографий проверена в браузере.

Файлы assets/compact-house.webp, family-house.webp, hero-house.webp — визуализации из предоставленного владельцем репозитория ibr-homes-template. Они не заявлены как выполненные объекты. Для замены фотографий: index.html; для каталога: module-data.js. Размеры и характеристики в схеме зон не утверждены: схема иллюстративная.
