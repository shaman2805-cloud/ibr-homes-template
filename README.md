# IBR HOMES — шаблон сайта

Адаптивный статический сайт для компании IBR HOMES. Это первая версия дизайна на основе информации из профиля компании и структуры каталога в предоставленном референсе.

## Как открыть

Откройте папку в Cursor, затем файл `index.html` в браузере. Сборка, пакеты и сервер не требуются.

## Файлы

- `index.html` — разметка и тексты страниц.
- `styles.css` — стили для компьютера и телефона.
- `script.js` — переключение форматов, мобильное меню и сообщение для WhatsApp.
- `assets/*.webp` — временные концептуальные визуализации домов. Это не фотографии реализованных проектов IBR HOMES.

Чтобы заменить визуализации собственными фотографиями, положите файлы в `assets/` и обновите пути в `index.html` и массиве `formats` в `script.js`.

Форма открывает подготовленное сообщение в WhatsApp по номеру из профиля IBR HOMES. На сайте нет сервера, базы данных и автоматической отправки заявки. Названия трёх форматов — условные варианты интерфейса, а не подтверждённый каталог компании.
