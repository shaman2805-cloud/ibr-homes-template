# IBR HOMES — версия 9, технические преимущества

Все разделы находятся в index.html: первый экран, о компании, преимущества, этапы строительства, горизонтальные карточки, технология, каталог, расчёт, участок, фото, FAQ, журнал и контакты. Внизу сохранена подпись designed by @batyrkhan999666.

## Открыть в Cursor
1. Сохраните копию предыдущей папки.
2. Распакуйте архив v9 и скопируйте всё содержимое в рабочую папку с заменой файлов, включая motion.css и motion.js.
3. Если сервер уже работает, оставьте его запущенным. Иначе выполните в терминале папки: `python3 -m http.server 8000`.
4. Откройте http://localhost:8000/ и нажмите Cmd+Shift+R.

Старые module.html и /module/ автоматически ведут на каталог единой страницы. Их можно оставить для старых закладок. Отдельной страницы каталога больше нет.

## Файлы для правок
- index.html — все разделы и окна.
- styles.css — базовые стили.
- module.css — каталог, формы, окна, FAQ.

- module.js — интерактивность, анимации, заявки.
- motion.css и motion.js — дополнительные анимации всей страницы и круговой сцены.
- module-data.js — четыре демонстрационные концепции и три материала журнала.
- calculator-config.js — WhatsApp и ставки, если они утверждены.
- assets/ — локальные визуализации.
- PHOTO-SOURCES.md — временные фото Pexels.

script.js от предыдущей версии оставлен для совместимости файлов, но не подключён к новой странице. Не правьте его для изменений v7.

## Анимации
- Первый экран закрепляется: изображение дома приближается, сменяется другим домом и раскрывает новый заголовок. Следующая секция появляется после завершения сцены. Прокрутка назад воспроизводит переход в обратном порядке.
- Детали преимуществ, технологии, этапов, журнала и контактов появляются при входе в экран; линии этапов раскрываются слева направо.
- На телефоне сцена короче; при уменьшении движения или низком экране закрепление первого экрана отключено.
- Появление крупного названия через маску.
- Смещение и масштабирование панорамного изображения при прокрутке.
- Закреплённый фон в разделе о компании, последовательное появление текста.
- Горизонтальная сцена из четырёх карточек с закреплением, прогрессом и короткой остановкой в конце.
- Закреплённая сцена с тремя этапами: поочерёдное прорисовывание кругов, подъём текста, масштабирование фона и индикатор прогресса. Движение связано с прокруткой и работает в обратную сторону.
- Плавные появления карточек, FAQ, фотографий, кнопок и подвала. На телефоне круги идут вертикально.
- Увеличение фотографий и движение элементов при наведении.
- Закреплённые переключатели каталога, смена изображения с прозрачностью и масштабом.
- Поочерёдное появление меню, плавное закрытие диалогов.
- Переходы шагов расчёта; раскрытие FAQ по высоте.
- Индикатор чтения страницы.

Основа — приёмы из https://homewoodspa.ru/ и https://homewoodspa.ru/module, самостоятельно реализованные для материалов IBR HOMES. Попиксельное совпадение каждого состояния не заявляется. В первом экране используется изображение с параллаксом, не оригинальное видео. На телефоне сцены идут вертикально; настройка системы «уменьшение движения» отключает анимации.

## Расчёт и заявки
Пять шагов: направление, параметры дома, участок, сроки/бюджет, имя/фамилия/телефон/согласие. Есть отдельные входы для участка, бюджета и короткого вопроса. Возврат сохраняет ответы в памяти открытой страницы.

Финальный шаг показывает заявку, затем клиент открывает WhatsApp и сам нажимает «Отправить». Сайт не хранит заявки в базе, не отправляет сообщения автоматически и не заявляет доставку сообщения после открытия окна. Номер компании: 77007249123.

Цены неизвестны, поэтому ставок нет. При добавлении положительной ставки в calculator-config.js появляется простой ориентир площадь × ставка; доставка, основание и дополнительные работы уточняются отдельно. Введённый клиентом бюджет не выдаётся за расчёт.
